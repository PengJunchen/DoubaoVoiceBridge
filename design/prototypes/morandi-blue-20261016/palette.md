# 莫兰迪蓝配色提案

状态：静态视觉原型，供用户评审。没有改动生产界面，也没有进行真实 UI 或功能验证。

快捷键以左 Option 作示例；设置页实际文案会随新录制的按键更新。

建议优先评审 A。它在浅色 macOS 窗口里最清晰，雾蓝集中在主操作、快捷键和图标上，保留原生留白。B 提供安静的深色工具感；C 用暖灰减少冷感，同时保留足够深的蓝灰操作色。

## A · 雾蓝浅色

清透、克制、容易融入 macOS 日常窗口。推荐。浅色桌面环境中最容易读，蓝色集中在快捷键、主按钮与图标上。

| 角色 | 色值 | 用途 |
|---|---|---|
| canvas | `#EFF3F4` | 窗口外层 / 背景 |
| surface | `#FFFFFF` | 窗口表面 |
| text | `#293842` | 主要文字 |
| muted | `#536874` | 说明文字 |
| accent | `#53778C` | 操作 / 快捷键 / 图标 |
| separator | `#C7D3D9` | 分隔线 / 边界 |

对比度：正文 `12.08:1`；说明文字 `5.83:1`；强调色与表面 `4.79:1`；主按钮文字 `4.79:1`。正文与说明文字目标为 WCAG AA 4.5:1，图形与大字目标为 3:1。

## B · 深灰蓝

沉静、专注、具有清晰的深色工具感。深色方向。图标与主操作用浅雾蓝提亮，界面整体保持石板灰蓝。

| 角色 | 色值 | 用途 |
|---|---|---|
| canvas | `#1F2A32` | 窗口外层 / 背景 |
| surface | `#2B3943` | 窗口表面 |
| text | `#F3F5F3` | 主要文字 |
| muted | `#C0C9CE` | 说明文字 |
| accent | `#96B3C1` | 操作 / 快捷键 / 图标 |
| separator | `#465861` | 分隔线 / 边界 |

对比度：正文 `10.83:1`；说明文字 `7.06:1`；强调色与表面 `5.38:1`；主按钮文字 `6.63:1`。正文与说明文字目标为 WCAG AA 4.5:1，图形与大字目标为 3:1。

## C · 暖灰蓝

温和、安定、接近纸感的暖中性色。暖色方向。灰蓝只做操作与键帽标记，表面带有柔和的暖灰底色。

|---|---|---|
| canvas | `#EAE8E1` | 窗口外层 / 背景 |
| surface | `#F8F7F2` | 窗口表面 |
| text | `#31383C` | 主要文字 |
| muted | `#5D686B` | 说明文字 |
| accent | `#506D7D` | 操作 / 快捷键 / 图标 |
| separator | `#C6C3BB` | 分隔线 / 边界 |

对比度：正文 `11.11:1`；说明文字 `5.35:1`；强调色与表面 `5.12:1`；主按钮文字 `5.49:1`。正文与说明文字目标为 WCAG AA 4.5:1，图形与大字目标为 3:1。

## 选择与生产实现（2026-10-16）

用户已选择 C「暖灰蓝」。配色已落实到 `apps/remote-voice-bridge/.build/fork-release`：新增 `BridgeTheme.swift`，在设置窗口和听写 Composer 中使用以下统一角色：canvas `#EAE8E1`、surface `#F8F7F2`、text `#31383C`、muted `#5D686B`、accent `#506D7D`、separator `#C6C3BB`。主按钮使用强调色，次级按钮和系统控件沿用原生 AppKit 状态与焦点表现。菜单继续使用系统原生样式，状态栏图标使用单色模板 SF Symbol。

已将本方案图标的可复现源文件写入 `Resources/AppIcon-source.svg` 和 `Resources/AppIcon-source.png`，生成 `Resources/AppIcon.icns`；十种尺寸的派生 PNG 保存在忽略目录 `.build/AppIcon.iconset/`，构建脚本仍从原路径复制 ICNS，LICENSE 未改。窗口通过 Aqua 外观和逐按钮 tint 使用主题；AppKit 的 `NSWindow` 没有 `contentTintColor` 属性，因此没有设置窗口级 tint。此实现尚待主代理完成完整构建和真实 GUI 验证；当前只做静态源码语法与资源尺寸检查，不代表产品 UI 验收。
