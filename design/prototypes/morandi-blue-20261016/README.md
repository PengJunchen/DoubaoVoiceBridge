# 莫兰迪蓝静态提案

设计问题：在保留简洁原生 macOS 操作和动态快捷键说明的基础上，选择应用图标、设置窗口与菜单的统一配色。

2026-10-16 提供 A 雾蓝浅色、B 深灰蓝、C 暖灰蓝三套静态原型。用户已明确选择 **C 暖灰蓝**。这些图片用于视觉决策；实现时保留紧凑默认窗口，按实际录制键更新文案。它们不构成功能或端到端验证。

本分支归档完整原型和绘图源文件，不加入上游 PR 或应用发行包。

- `overview.png`：三套对比。
- `proposal-*.png`：高清单案。
- `icon-*.svg/png`：图标源文件。
- `palette.md/json`：颜色用途与对比度。

本机安装 Pillow 后运行 `python3 render_proposals.py` 可重新生成图片；脚本使用 macOS 系统字体。
