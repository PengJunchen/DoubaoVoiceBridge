# DoubaoVoiceBridge（远控听写·自动适配）

macOS 菜单栏工具：在 UU 远控处于前台时，用你选择的按键触发本机豆包语音输入法，在临时文本框中接收识别文字，再通过 UU 剪贴板同步粘贴到远端 Mac 的当前输入框。

> 本项目是非官方的个人自动化工具，与豆包、字节跳动、UU 远控或网易没有隶属、合作或授权关系。相关名称与商标归各自权利人所有。

## 快捷键适配

打开应用会显示“远控听写设置”，先确认豆包实际使用的语音键与开始方式，再选择远控听写的触发键。首次配置完成前不启用快捷键监听；未保存而关闭窗口也不会默认接管按键。保存后，关闭设置窗口可继续在菜单栏运行。之后可再次从 Finder 打开应用，或从菜单栏“设置豆包与远控按键…”进入设置；听写进行中会提示先结束听写。

豆包语音键有三种配置来源：

- **自动读取**：优先通过辅助功能读取已打开、未最小化的豆包“语音输入”设置窗口，再尝试候选偏好字段。不同豆包版本的偏好存储可能不同；读取不可用时应手动确认，不能假设已访问内部配置。
- **上次确认**：自动读取不可用且豆包设置窗口未打开时，可使用保存的有效模式，不需要一直打开豆包设置。
- **手动选择**：读不到时，由用户选择与豆包设置一致的按键和模式。手动配置优先于后续自动读取，直至用户主动切回自动来源。

目前豆包语音模式支持 **Fn 免按**（单击开始、任意键结束）和 **左 Control 长按**（按住说话、松开结束）。手动配置采用明确选项，尚不支持录制任意按键或组合键。自动读到未知、组合、冲突或关闭的快捷键时，不会用历史模式掩盖当前不受支持的配置。工具不会更改豆包自己的设置。

远控触发键可选择 **跟随豆包按键** 或 **左 Control 长按**。例如豆包保持 Fn 免按模式，你在 UU 中按住左 Control 时，工具会在本机发送独立的 Fn 触发；松开 Control 时发送结束键，等待识别文字后粘贴到远端。合成 Fn 不携带物理 Control 修饰状态。活动听写使用启动时的完整配置，空闲时才刷新。

设置窗口提供“打开 TextEdit 进行本机识别测试…”入口，请在其中新建空白文稿，用豆包自己的按键确认真实识别，再在 UU 的测试文稿验证远程粘贴。保存设置与通过自检不代表完成真人语音验收。

应用图标采用“麦克风与远程桥接”主题，由图像生成工具制作。原图为 `Resources/AppIcon-source.png`，应用使用 `Resources/AppIcon.icns`。

## 运行要求

- macOS 13 或更高版本
- Intel 或 Apple Silicon Mac
- 已安装并启用豆包语音输入法
- 已安装 UU 远控，且本机与远端 Mac 可以正常连接和同步剪贴板
- 辅助功能权限（读取豆包设置文本并控制本机听写框）
- 输入监控权限（监听快捷键）

麦克风权限只需要授予豆包语音输入法，本工具本身不录音。当前实现通过 Bundle ID `com.netease.uuremote` 识别 UU 远控；相关应用更改 Bundle ID 或输入行为时，项目可能需要同步调整。

## 从源码构建

需要 Xcode Command Line Tools 和 Swift 5.9 或更高版本。

```bash
git clone https://github.com/yupeng316888-create/DoubaoVoiceBridge.git
cd DoubaoVoiceBridge
./scripts/build-app.sh
open dist
```

构建脚本会生成通用二进制 `dist/远控听写·自动适配.app`，对其做 ad-hoc 签名，并运行内置自检和只读诊断。该构建没有 Apple Developer ID 签名，也未经过公证。首次启动后，可在“系统设置 → 隐私与安全性”中为该应用开启辅助功能和输入监控；也可从菜单栏查看权限入口。

构建脚本直接从命令行运行打包二进制的 `--diagnostics`。权限和事件监听探测结果只代表这次命令行执行上下文；它可能使用终端或宿主进程已有的授权，不能证明“远控听写·自动适配”这个图形应用已获授权。请在系统设置中分别核对该应用的辅助功能和输入监控开关，并通过实际启动的图形应用验证监听行为。

## 工作原理与安全边界

- 只在 UU 远控是当前前台应用时接管已识别的快捷键。
- 在本机显示临时文本框，让豆包语音输入法把识别结果写入其中。
- 结束听写后等待输入法提交最终文字，再把文字暂存到系统剪贴板。
- 自动粘贴前重新确认同一个 UU 进程和同一个原聚焦窗口；焦点变化时取消操作。
- 明确发送完整的 `Command` 按下、`V` 按下、`V` 松开和 `Command` 松开事件序列，避免远端只收到字母 `V`。
- 粘贴完成后，仅在剪贴板未被其他程序改动时恢复原内容。
- `--diagnostics` 只读取权限、进程和快捷键窗口的结构化摘要，不输出设置窗口正文。

本工具不调用豆包账号或语音服务，不保存听写正文，也不包含网络请求。网络传输与剪贴板同步由豆包语音输入法和 UU 远控各自完成。

## 测试与诊断

```bash
swift run DoubaoVoiceBridge --self-test
swift run DoubaoVoiceBridge --diagnostics
```

内置自检覆盖长按与 Fn 切换状态机、设置文本解析、组合键拒绝、Fn 伴随事件与配对释放清理、配置保存与自动刷新、独立桥接映射、合成 Fn 修饰状态、识别文本稳定等待、延迟配置迁移、UU 同步安全下限和听写框布局。`--diagnostics` 的授权结果仅适用于实际执行该命令的进程；从终端运行时，不能当作图形应用自身的授权证明。

提交源码时应排除设备日志、听写正文、截图、账号配置、构建产物和个人目录。`.gitignore` 已排除本机验收记录与生成元数据；不要把这些文件作为公开问题附件上传。
